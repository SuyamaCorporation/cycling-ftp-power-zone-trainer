# サイクリング FTP パワーゾーン トレーナー

FTP（W）と体重（kg）を入力するとTrainingPeaks式7ゾーンのW範囲を表示するトレーニング計算ツール。

## 機能
- FTP（W）と体重（kg）を入力
- TrainingPeaks式 7ゾーン計算
  - Z1: Active Recovery (<55%)
  - Z2: Endurance (55-75%)
  - Z3: Tempo (75-87%)
  - Z4: Threshold (87-95%)
  - Z5: VO2 Max (95-105%)
  - Z6: Anaerobic (105-120%)
  - Z7: Neuromuscular (>120%)
- W/kg比表示
- 各ゾーンのWatt範囲と説明
- カラー棒グラフで視覚化
